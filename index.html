02 Grabar desde iPhone

Safari y Chrome en iPhone no pueden grabar NFC desde una página web (Apple no lo permite). Pero la etiqueta sí se lee sola en iPhone. Para grabarla usa la app gratuita NFC Tools:

  1. Toca Copiar URL.
  2. Abre NFC Tools → Escribir → Añadir un registro → URL / URI.
  3. Pega la URL, toca Escribir y acerca la etiqueta a la parte superior del iPhone.
